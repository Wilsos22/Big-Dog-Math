Run the `bdm-status` skill from this plugin. Read its SKILL.md in full before
doing anything, and follow it exactly - the ground rules, the ranking, and the
report shape are the point of it.

**Mode for this run: `$ARGUMENTS`**

Empty means the default status pass. `sweep` means read THIS conversation for
changes that were named out loud and never written down, catalog them, show the
catalog, and STOP for confirmation before filing. `sync` means the status pass
plus landing the corrections. Anything else is an area name and scopes the
status read to that one surface or feature.
